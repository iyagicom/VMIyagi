# VMIyagi

**"내 PC 에서는 되는데"로는 부족합니다. 깨끗한 리눅스에서 몇 초 만에 시험하세요 — 설치하고, 실행하고, 확인하고, 초기화, 반복.**

[English](README.md) · [한국어](README_ko.md)

## 왜 VMIyagi 인가

- **클릭 한 번이면 깨끗한 상태로.** 스냅샷은 바뀐 부분만 저장해서 빠르고 용량을 거의 안 씁니다. 초기화하면 저장해 둔 그때 그대로 — 시험할 때마다 OS 를 다시 깔 필요가 없습니다.
- **버튼 하나로 패키지 시험.** `.deb`·`.rpm`·`.pkg.tar.zst`·AppImage·zip 을 고르면 **Run Test** 가 게스트에 설치하고, 실행하고, 살아 있는지 확인하고, 로그를 모아 옵니다.
- **복사·붙여넣기·공유폴더가 설정 없이.** 게스트에서 명령 한 줄이면 클립보드·화면 크기 자동 맞춤·공유폴더가 됩니다.
- **우분투·데비안·페도라·아치 — 그리고 Windows 11.** Windows 11 은 UEFI + TPM 2.0 으로 설치되고, 클립보드·공유폴더도 됩니다.
- **만들어진 이미지로 바로 시작.** 배포판이 내놓는 qcow2 이미지를 가져와 설치 없이 부팅합니다.
- **가볍게.** VirtualBox 처럼 다 하는 VM 관리자가 아니라, QEMU/KVM 위에 이 반복 작업에 필요한 것만 올린 작은 창입니다.

## 기능

| | |
|---|---|
| **스냅샷 / 초기화** | 바뀐 부분만 저장, 스냅샷마다 따로 부팅 |
| **Run Test** | 고른 패키지로 설치 → 실행 → 생존 확인 → 로그 |
| **게스트 도구 CD** | 명령 한 줄로 클립보드·화면 크기 자동 맞춤·공유폴더 |
| **공유폴더** | 호스트 폴더가 게스트 `/mnt/<이름>` 에(Windows 게스트는 드라이브 문자) |
| **데이터 CD** | 폴더를 ISO 로 구워 CD 로 붙이기 — 큰 설치 파일 옮길 때 |
| **복제** | 원본과 파일을 전혀 공유하지 않는 독립 VM |
| **디스크 이미지 가져오기** | 배포판 qcow2 이미지로 바로 시작 |
| **Windows 11 게스트** | UEFI + TPM 2.0 |
| **한/영·한자 키** | QEMU 창으로 전달되지 않는 키를 대신 눌러 줌 |

## 다운로드

**[⬇ 최신 버전 받기](https://github.com/iyagicom/VMIyagi/releases/latest)**

| 내 시스템 | 받을 파일 |
|---|---|
| Ubuntu 24.04 · 데비안 | **ubuntu24.04** 가 붙은 `.deb` |
| Ubuntu 26.04 | **ubuntu26.04** 가 붙은 `.deb` |
| 페도라 · openSUSE | `.rpm` |
| 아치 · 만자로 | `.pkg.tar.zst` |
| 그 밖의 리눅스 | `.AppImage` 또는 `.zip` |

**필요한 것:** 가상화(KVM)가 켜진 x86-64 PC 와 `qemu-system-x86`·`qemu-utils`. `.deb` 로 설치하면 이것들과 함께, 있으면 좋은 도우미(공유폴더용 `virtiofsd`, CD 용 `xorriso`, Windows 11 용 `ovmf`+`swtpm`)까지 같이 깔립니다.

```bash
sudo apt install ./vmiyagi_*_amd64.deb       # 우분투 / 데비안
```
